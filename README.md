# 📘 Электронный дневник студента

Веб-приложение для автоматизации учебного процесса.

## 🚀 Возможности
- **Администратор:** управление пользователями, группами, предметами и расписанием (верхняя/нижняя неделя).
- **Преподаватель:** создание/редактирование ДЗ, прикрепление файлов, статистика сдачи.
- **Студент:** просмотр заданий, скачивание файлов, отметка о выполнении, диаграмма Ганта.

## 🛠 Стек
Python (Flask), PostgreSQL, SQLAlchemy, JS (amCharts), HTML/CSS.
